# 範圍

## MVP

GTTS 是以 TX／MTX 為核心的研究、歷史回測、paper signal 與解釋性研究介面。第一階段只建立資料時間契約、事件 schema、離線 smoke 與品質工具骨架；策略、資料下載、撮合、損益與介面尚未實作。

MVP 禁止實單交易。法人部位、期現貨基差與波動量價只作可觀測代理變數，不能據此宣稱已觀測玩家策略或納許均衡。基差單腿策略是方向性研究，不稱無風險套利。

## 資料與契約

資料來源預計包含 TAIFEX 期貨與法人資料、TWSE 指數資料，以及具授權時可替換的同步盤中資料 adapter。尚未確認的端點、歷史範圍與授權都保留為待查項目，不假設可免費取得。契約規格、交易時段、最後交易日、稅費與保證金應依生效日期設定，不硬編成永久常數。

## 交付邊界

目前交付只涵蓋 PR-01：專案設定、資料字典、初步決策紀錄、Pydantic 事件 schema、schema 測試、離線 smoke 與 CI。此交付不代表已完成策略研究、可信回測或 GitHub PR。
