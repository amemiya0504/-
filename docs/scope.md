# 範圍

## MVP

GTTS 是以 TX／MTX 為核心的研究、歷史回測、paper signal 與解釋性研究介面。已建立資料時間契約、事件 schema、離線 smoke、交易日曆與日資料 adapter。策略、撮合、損益與介面尚未實作。

MVP 禁止實單交易。法人部位、期現貨基差與波動量價只作可觀測代理變數，不能據此宣稱已觀測玩家策略或納許均衡。基差單腿策略是方向性研究，不稱無風險套利。

## 資料與契約

日資料來源包含 TAIFEX 期貨與法人資料、TWSE 指數資料。同步盤中資料仍待確認歷史範圍與授權。契約規格與交易時段依生效日期設定，最後交易日可用公告覆寫。稅費與保證金留待後續設計。

## 交付邊界

目前交付涵蓋 PR-01 的研究骨架，以及 PR-02 的日曆、日資料 adapter、SQLite 擷取與離線測試。
