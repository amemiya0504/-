# 範圍

## MVP

GTTS 是以 TX／MTX 為核心的研究、歷史回測、paper signal 與解釋性研究介面。已建立資料時間契約、事件 schema、離線 smoke、交易日曆、日資料擷取、離線回測、S1 法人研究及 S2 同步基差研究。Fubon 期貨歷史 5 分 K adapter 目前只保留 raw 行情；真實盤中資料、開盤撮合證據、授權與策略績效尚未確認。

MVP 禁止實單交易。法人部位、期現貨基差與波動量價只作可觀測代理變數，不能據此宣稱已觀測玩家策略或納許均衡。基差單腿策略是方向性研究，不稱無風險套利。

## 資料與契約

日資料來源包含 TAIFEX 期貨與法人資料、TWSE 指數資料。同步盤中資料仍待確認歷史範圍與授權。契約規格與交易時段依生效日期設定，最後交易日可用公告覆寫。稅費與保證金留待後續設計。

## 交付邊界

研究骨架、資料時點規則、日資料擷取、離線回測、S1 與 S2 研究策略皆可用合成 fixture 重現。Fubon raw adapter 不會登入或呼叫下單 API；回補歷史資料的可用時間只代表首次擷取時間，不能當作歷史即時可得時間。尚未確認真實盤中 TAIEX 歷史來源及資料授權，也沒有可宣稱的真實 OOS 績效。
