# 決策紀錄

## ADR-0001：MVP 限定離線研究

- 狀態：已採用
- 決策：先提供 Python 3.12、Pydantic schema、離線測試與 smoke 骨架；不接真實來源、不連券商、不產生實單。
- 原因：先把資訊可得時間與事件資料契約固定，避免把盤後資料誤用於盤中決策，也避免未確認來源授權。
- 後果：目前不能產生策略訊號、成交、損益或績效報告。

## ADR-0002：時間欄位與可得時間

- 狀態：已採用
- 決策：事件時間使用 timezone-aware `datetime`，明示 `Asia/Taipei`。市場資料事件須先發生才可取得。已知的 `published_at` 必須介於事件與取得時間之間，`available_at` 最早為公布時間。缺少 `published_at` 時，`available_at` 最早為首次取得時間。
- 原因：事件發生時間不等於資訊公開或策略可用時間。
- 後果：未知公布時間需由未來來源 adapter 套用保守延遲，不能由 schema 猜測。

## ADR-0003：精確數值型別

- 狀態：已採用
- 決策：訂單數量採整數，價格採 `Decimal`。
- 原因：為後續成本與損益帳務避免二進位浮點數表示誤差。
- 後果：金額精度、稅費捨入規則仍須在回測引擎設計時明訂並以手算案例驗證。
