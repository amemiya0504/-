# 回測協定（規劃）

回測尚未實作。本文件先固定不可違反的時間與成交原則，細部事件排序、費用公式與 golden cases 留待回測引擎 PR 設計及審查。

- 依 `available_at` 排序資訊；每次決策只使用 `available_at <= decision_at` 的資料。沒有可靠 `published_at` 時採保守延遲並標示推定，不能回填成開盤前可用。
- 僅使用已完成 K 棒。訊號只能在形成後提交，成交時間必須晚於訊號時間且符合下一個合法可交易事件。
- 訊號與成交按實際 TX／MTX 合約價格記錄。連續期貨序列只作特徵，不作實際成交價或損益價格。
- 交易日、日夜盤、跨午夜歸屬、最後交易日與換月規則由有效日期日曆決定；目前尚無交易日曆實作。
- 手續費、交易稅、滑價、保證金、逐日盯市、缺口與強制減倉必須分開記錄；保證金不是交易成本。
- 預先固定 train／validation／最終 OOS 與 purge／embargo；標準化、校準與門檻只能用訓練資料估計。不可因 OOS 表現調參或隱藏失敗結果。
- 缺資料、交易數不足或授權未知時，明確標示限制或「樣本不足／未證實」，不補造績效。
